# Dynamic Storm

## *Description*

Animation that simulates an evolving storm, then subsequently allows the user to switch from stormy to sunny.

## *Features*

- Cloud formations dependent on storm level
- Smooth transition with manipulation of light, rain, and cloud density
- Instanced mesh for realistic rain evolution
- No image assets used

## *Use Cases*
- Web backgrounds
- Game development
- Interactive tech art
- Audiovisual projects
